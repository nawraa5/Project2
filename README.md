#MOMENT

#Overview

MOMENT is a web application for flower and cake stores. Users can browse stores and products, create accounts, and manage orders. Store owners can manage their own stores and products.

#Technologies Used:

HTML
CSS
JavaScript
Node.js
Express.js
MongoDB
Mongoose
EJS
Express Session

#Features

User authentication
Customer and owner roles
Store CRUD operations
Product CRUD operations
Order CRUD operations
Role-based access control
Flower and cake categories
icon for the app
Amazing style css

#Getting Started:

#Requirements:

Node.js
MongoDB
VS Code

#Installation:

Clone the repository.
Open the project in VS Code.

#Install dependencies:

```bash
npm install

Create a .env file:
MONGODB_URI=your_mongodb_connection_string
SESSION_SECRET=your_session_secret

#Start the application:
node server.js


Open the application:http://localhost:3000


#Database
User – account and role information
Store – store information and owner
Product – product information and store
Order – customer, products, price, and status
